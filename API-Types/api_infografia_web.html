API Cheat‑Card

¿Qué es una API?

Un mensajero digital entre tu app y un servidor: tú pides datos y él te los trae.

Tipos principales

🔗 REST

URLs como /users/3. Simple y universal.

🧬 GraphQL

Un solo endpoint; pides exactamente lo que necesitas.

📜 SOAP

XML, formal, usado en grandes corporaciones.

📩 Webhooks

El servidor te envía eventos cuando ocurren.

🌐 WebSockets

Comunicación en tiempo real.

Ejemplos en Python

REST

import requests
r = requests.get("https://api.example.com/users/1")
print(r.json())

GraphQL

import requests
query = """
query { user(id: 1) { name email } }
"""
r = requests.post("https://api.example.com/graphql", json={"query": query})
print(r.json())

SOAP

from zeep import Client
client = Client("https://example.com/service?wsdl")
print(client.service.GetUser(id=1))

Webhook

from fastapi import FastAPI, Request
app = FastAPI()
@app.post("/webhook")
async def webhook(req: Request):
    print(await req.json())

WebSockets

import websockets, asyncio
async def main():
    async with websockets.connect("wss://echo.websocket.events") as ws:
        await ws.send("hola")
        print(await ws.recv())
asyncio.run(main())
